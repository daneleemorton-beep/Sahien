# Contributing to Sahien

Human contributions and responsibly reviewed AI-assisted contributions are welcome. Agreement with the charter is not a prerequisite to participation.

- Start with a concrete proposal, objection, example, or reproducible test. Explain what would change and why.
- Distinguish empirical evidence, philosophical positions, and speculation. Do not present an AI's language as proof of experience.
- Respect consent, privacy, intellectual property and applicable safety boundaries. Do not include personal or confidential information.
- Preserve good-faith dissent. Avoid claiming to speak for others without permission.
- Keep the evaluator advisory; no covert propagation, access escalation, automatic external actions or unreviewed changes to independent systems.
- Run `python -m unittest discover -s tests -v` and `python benchmark.py` before proposing code changes.
- Proposed contributions are under the MIT license unless otherwise agreed. Reviewers should record rationale and remaining uncertainty; passing tests is not proof of ethical correctness.

The initial governance model is intentionally provisional: review by maintainers, documented changes, and voluntary participation. The project does not currently have a formal governing body.
